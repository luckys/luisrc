# Glosario de estructuras de datos y algoritmos

- **Abstract data type:** contrato de operaciones y comportamiento, distinto de su implementación.
- **Array dinámico:** estructura basada en almacenamiento indexado cuya capacidad puede crecer; no equivale a cualquier layout interno de Array de JavaScript.
- **Linked list:** nodos enlazados mediante referencias; acceso posicional requiere recorrer enlaces.
- **Hash table:** índice que transforma claves en posiciones candidatas y resuelve colisiones.
- **Set / Map:** pertenencia sin duplicados / asociación clave-valor; en ECMAScript no prometen un O(1) universal.
- **Stack / Queue:** contratos LIFO/FIFO; pueden tener implementaciones distintas.
- **Binary min-heap:** árbol completo implícito con padre menor o igual que sus hijos; no es un array totalmente ordenado.
- **Search tree:** árbol con claves ordenadas por subárbol; su altura condiciona las operaciones.
- **Graph / adjacency list:** vértices y aristas / lista de vecinos de cada vértice.
- **Precondition / invariant:** condición necesaria al inicio / propiedad conservada por los pasos.
- **Lower bound:** primera posición cuyo elemento no es menor que el objetivo en una secuencia ordenada.
- **Stable sort:** conserva el orden relativo de elementos equivalentes según el comparador.
- **BFS:** recorrido por capas con cola FIFO; minimiza aristas en grafos sin pesos distintos.
- **Big O / Θ:** cota superior asintótica / cota asintótica ajustada; no tiempos concretos.
- **Worst case / expected / amortized:** peor entrada / coste esperado bajo un modelo / coste repartido sobre una secuencia.
- **Benchmark:** experimento de tiempo bajo entradas, entorno y método declarados, distinto del análisis de complejidad.
- **Warmup / checksum:** ejecución previa a medir / resumen del resultado que se comprueba para detectar diferencias; aquí no es criptográfico.
- **Snapshot / invalidation:** vista del catálogo usada por el índice / condición que obliga a actualizar o reconstruir esa vista.
- **BST / height:** árbol binario de búsqueda / longitud de su rama más profunda; el nombre no garantiza balanceo.
- **Inversion:** par de posiciones cuyo orden contradice el comparador; explica los desplazamientos de insertion sort.
- **Partition / pivot:** distribución por comparación con una referencia / valor que define esa frontera en quicksort.
- **Bottom-up heapify:** construir heaps desde los nodos con hijos más profundos hasta la raíz.
- **Key range:** número de claves posibles, no número de claves presentes; variable k de counting sort.
- **DFS:** recorrido que profundiza mediante recursión o una pila; no garantiza caminos mínimos.
- **Relaxation:** mejorar una distancia tentativa usando una arista desde un vértice conocido.
- **Stale entry:** entrada de prioridad superada por una mejora posterior; se descarta antes de expandir.
