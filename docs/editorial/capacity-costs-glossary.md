# Glosario de capacidad y costes

Complementa [servicios fiables](reliable-services-glossary.md). Definiciones de
esta serie, con límites explícitos:

| Término | Definición usada |
| --- | --- |
| RPS | Peticiones por segundo en un punto declarado; distinguir ofrecidas, admitidas y completadas. |
| Concurrency | Trabajo simultáneamente dentro del límite definido; no cores ejecutando en paralelo. |
| Little's Law | Relación entre cantidad media, tasa media y estancia media de una población compatible en régimen adecuado. |
| CPU demand | Tiempo de CPU por operación; distinto del tiempo completo esperando y ejecutando. |
| Utilization | Consumo dividido por capacidad de referencia en un intervalo; declarar referencia. |
| Headroom | Margen elegido para variación o fallo declarado; no garantía de disponibilidad. |
| Bottleneck | Recurso cuyo techo limita el throughput bajo los supuestos analizados. |
| Readiness | Preparación para recibir tráfico, distinta de intención de escalar. |
| Cost/req | Coste de alcance/periodo dividido por peticiones de alcance/periodo compatibles. |
| TCO | Coste total de propiedad bajo un alcance definido; distinto de nuestro subtotal de cinco partidas. |
| Commitment | Obligación de gasto/uso según contrato, con riesgos de elegibilidad y ociosidad. |
| Capacity reservation | Mecanismo para asegurar capacidad bajo atributos y condiciones; no sinónimo de descuento. |
| Unit economics | Métricas que relacionan costes y uso con unidades técnicas o de negocio definidas. |
| Allocation | Política explícita de atribución de costes; conservar el total no prueba causalidad. |
| Estimate / budget / forecast | Cuenta bajo supuestos / gasto autorizado / previsión revisable con nueva evidencia. |
| microUSD | Millonésima de dólar usada como unidad entera de cálculo, no float monetario. |
