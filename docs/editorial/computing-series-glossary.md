# Glosario: Computación, sistemas y redes

| Término                           | Significado usado                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------ |
| CPU cache / page cache            | Bloques cerca de CPU / contenido de ficheros conservado en RAM por el SO             |
| Locality                          | Reutilización temporal o proximidad espacial que puede aprovechar un acceso          |
| Checksum                          | Resumen simple para comprobar igualdad del trabajo, no autenticación criptográfica   |
| Process / thread                  | Espacio de recursos y direcciones / contexto de ejecución dentro del proceso         |
| RSS / heapUsed                    | Memoria residente del proceso / memoria del heap JS usada según V8                   |
| File descriptor                   | Referencia del proceso a un recurso abierto                                          |
| Signal                            | Notificación al proceso; SIGTERM permite handler, SIGKILL no                         |
| Resolver / authoritative          | Cliente o servidor que resuelve / autoridad que publica una zona                     |
| TTL                               | Tiempo de vida de la respuesta DNS bajo las reglas de caché, no cierre de conexiones |
| Flow control / congestion control | Proteger capacidad del receptor / adaptar envío a recursos de red                    |
| Head-of-line blocking             | Información posterior retenida por un hueco anterior en una entrega ordenada         |
| Trust anchor / SAN                | Base de confianza del cliente / identidades del certificado para el servicio         |
| ETag / validation                 | Validador de representación / comprobar si una copia puede reutilizarse              |
| Task / microtask                  | Trabajo programado por el event loop / trabajo procesado en sus checkpoints          |
| Origin / site                     | Esquema-host-puerto / concepto distinto usado, entre otras cosas, por SameSite       |
