Atención desde sus matrices

Pesos inicializados, sin entrenamiento ni calidad predictiva medida. CPU float64. Nueve casos de atención y tres inicializaciones de cada arquitectura. Tablas con notación científica para magnitudes extremas; cero y ausencia de dato se distinguen.

Cargando observaciones…

1. Una query combina values de keys permitidas

La escala de pesos es siempre 0…1. Cruz gris: acceso excluido por la máscara. Query en padding no implica una fila de ceros; se indican los pasos válidos.

Los casos self_full/self_causal/cross usan vectores aleatorios fijados. Las otras etapas proceden de bloques completos sobre IDs. Las proyecciones se inicializan, no aprenden significados en este laboratorio. Los errores frente a APIs nativas solo se publican para los tres casos aislados.

2. Escala y estabilidad de softmax

512 queries y ocho keys por dimensión, componentes normales independientes. El eje usa dimensiones discretas, igualmente espaciadas en la figura. Entropía en nats; no representa calidad o calibración.

Nuestra función rechaza filas sin ninguna key permitida. El resultado de SDPA para ese caso pertenece al runtime observado; no se presenta como un contrato universal de todas las APIs. Dropout se fija explícitamente en cero.

3. Posición y permutaciones

Sin posiciones, permutar tokens permuta las salidas. Mantener posiciones fijas y mover solo tokens cambia la asociación. Permutar juntos tokens y posiciones conserva la equivarianza de ese conjunto de vectores. Son casos diferentes.

4. Causalidad del modelo completo

Gradiente del logit [muestra 0, posición 1, clase 1] respecto a embeddings de la muestra 0. Las posiciones 2…4 son futuras para esa salida. El mapa usa escala simétrica local; la tabla conserva números originales. No es una explicación causal de una clase aprendida.

Se cuentan elementos y bytes de un tensor denso de scores B=2, H=2 y float64. No son VRAM total, latencia, benchmark de GPU ni memoria de un kernel fusionado. Doblar longitud cuadruplica este tensor aunque haya máscara causal.
