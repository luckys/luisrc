De la medición agregada a una operación concreta

Resultados archivados de Chromium, una API Node y un worker en otro proceso. Este visor no abre conexiones al laboratorio ni genera tráfico.

Los tiempos son observados, no un benchmark. API y worker comparten máquina; en hosts distintos el clock skew puede alterar la alineación. El ancho del span no equivale a CPU consumida.
